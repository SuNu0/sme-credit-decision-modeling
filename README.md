# 中小微企业信贷决策数学建模（初版）

本仓库是 2020 年全国大学生数学建模竞赛 C 题“中小微企业的信贷决策”的一套完整初版方案，包含数据预处理产物、模型代码、求解结果、模型检验以及可由 Overleaf 编译的 LaTeX 论文。

> 当前版本定位为比赛备战初稿，重点保证模型链条完整、代码可运行、结果可复现。论文表达、参数依据和业务解释仍可继续迭代。

## 模型框架

1. **有信贷记录企业**：CRITIC 客观赋权 + TOPSIS 经营安全度 + 类别加权 Logistic 违约预测，并求解贷款利率与额度。
2. **无信贷记录企业**：使用 CORAL 领域自适应迁移违约规律，通过 Bootstrap 估计预测不确定性，在 1 亿元预算下配置贷款。
3. **突发事件调整**：结合行业冲击、企业暴露度和一阶风险传播生成 Monte Carlo 情景，以均值--P95 稳健风险配置方案，并使用 CVaR 检验尾部损失。

## 主要结果

| 模块 | 关键结果 |
|---|---|
| 问题一 | 重复五折 AUC 0.8030；5000 万元配置给 99 家企业；预期净收益 34.10 万元 |
| 问题二 | CORAL 协方差差异降低 99.99%；1 亿元配置给 239 家企业；预期净收益 163.11 万元 |
| 问题三 | 1200 个情景下 CVaR 从 120.21 降至 102.96 万元，下降 14.35% |
| 鲁棒性 | 输入增加 10% 噪声后，三个模型的风险排序 Spearman 均高于 0.988 |

## 快速运行

推荐 Python 3.11 或更高版本。

```bash
pip install -r requirements.txt
python code/model_solver.py
python code/result_analysis.py
python code/model_validation.py
```

实际验证环境：Python 3.14.5、NumPy 2.5.1、Pandas 3.0.5、OpenPyXL 3.1.5。程序随机种子固定为 `2020`。

原始附件 1、附件 2 和题目压缩包体积较大，且属于竞赛公开题目附件，本仓库不重复分发。`outputs/data_stage/2020C_数据预处理与特征库.xlsx` 已包含程序求解所需的企业级处理后特征；小型利率--流失率统计表保留在 `C/` 目录。

## 当前局限

- 源域仅有 123 家企业，概率校准仍有改进空间；
- 302 家目标企业没有真实违约标签，CORAL 检验主要反映统计分布对齐；
- 行业冲击和风险传播属于情景化近似，尚未还原完整供应链网络；
- 1 亿元采用必须完全投放的等式约束，现实应用可增加允许保留流动性的对照方案。
